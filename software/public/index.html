Engineered for Fail-Safe Operation

Dual-Probe Temperature Differential

Direct winding hotspot probe (T1) and ambient intake airflow probe (T2) deliver continuous ΔT thermal differential monitoring with 0.0625°C precision.

Rolling Trend Extrapolation

An ordinary least-squares regression calculates temperature rate-of-rise over a 30-sample sliding window to anticipate thermal breaches 30 seconds ahead.

Fail-Safe Hardware Isolation

Active-low optocoupler interlock instantly cuts off transformer output rails if core temperature reaches 65.0°C or forward projection exceeds 70.0°C.

Continuous Standby Telemetry

Microcontroller runs on uninterrupted +5VSB auxiliary standby power, maintaining sensor monitoring and alert connectivity even during a main trip.

Thermal Overtemperature Trip Alerts

Dispatches an immediate incident email when measured core temperature (≥ 65.0°C) or projected temperature (≥ 70.0°C) breaches safety limits. Protected by a 15-minute deduplication guard.

Emergency Manual Cutoff Override Dispatches

Dispatches an immediate notification whenever an operator or administrator triggers the manual Emergency Stop override to sever load rails.

Remote Power Output De-energize Notices

Dispatches a notification when main output rails are turned OFF remotely, containing the safety advisory regarding residual core heat and stored capacitor energy.
